# 写作方法与审读

## 把文字写到一个具体的人身上

采用“事件—本人重视的事—钱的作用—留下的选择”顺序。数字、情绪与意义分别举证：系统能证明钱何时变动，只有本人确认才能证明为何变动、当时如何感受。

先选择一个有画面的事实，再决定要不要一个比喻。每封信至多一个核心意象；没有生活细节时采用朴素表达，不制造雨夜、深夜、家人或独自扛过的场景。

允许平凡、尚未完成、改变计划和退出。无需把每个人写成长期主义者，也无需把每段经历写成逆境翻盘。

## 具体写法

| 场景 | 避免 | 原创替代表达 |
| --- | --- | --- |
| 账户亏损 | 亏损是你成长的勋章 | 截至这个日期，投资损失确实是……。它需要被看清。 |
| 有取用 | 你没守住长期投资 | 这笔钱在你确认的日期被取用。若用途已经确认，可以写清它完成了什么。 |
| 低活跃 | 你从未动摇 | 今年的账户记录已整理好。上次写下的目标，现在是否还适用？ |
| 有盈利 | 你的眼光战胜了市场 | 按这次对账口径，投资损益为……。投入和取用另外列示。 |
| 新用户 | 你已经走过了风雨 | 这份档案可以从你愿意写下的一件事开始。 |
| 已赎回 | 你错过了后来的上涨 | 我们把此前的记录留给你；你可以决定是否继续补充。 |
| 生活目标未确认 | 你为家人默默撑起未来 | 这笔钱想用在哪里，暂时留给你自己填写。 |
| 关系感 | 只有且慢懂你 | 这些记录有遗漏时，你可以改写。你的说明会让它更准确。 |

## 字句与节奏

- 使用准确动词、短段落和自然称呼。默认“你”；客户既有沟通偏好为“您”时保持一致。
- 信的开头尽快进入事实，不以宏观市场综述开头。
- 保留温和的审美与善意；不堆叠花开、星辰、远方、岁月等意象。
- 避免“我们知道你每一次深夜的焦虑”“你比99%的人更勇敢”“财富终会奖赏你”等无依据判断。
- 不用客户资产高低决定赞美强度；不以性别、职业、年龄推断责任感或风险偏好。
- 不模仿作者标志性句式、惯用口头禅或签名，不假扮作者。
- 原话可少量使用；客户没说过的话只能标作“给你留的一行空白”，不能加引号装成其自述。
- 来信中需要说出亏损、费用、服务未完成时直接说；不要用生活意义将其抵消。
- 在结尾提供一个具体选择或一个可跳过的问题。不要在温情结尾埋产品推介。

## 编辑评分

每项0–2分，属于内部编辑判断，不代表用户真实评价：
1. 事实准确：数字、时间、范围、个体归属均可核对。
2. 个人相关：至少一个他人无法套用的事实；资料不足时真实地留白。
3. 语言自然：可被自然朗读，空泛形容词少，段落有呼吸。
4. 尊重自主：不训诫、不评判买卖、不替客户定义人生意义。
5. 值得保存：包含一件具体记录、一个准确发现或一个本人愿意补充的问题。

建议事实准确和尊重自主必须各得2分，总分至少8分再进入发布候选。这是人工编辑门槛建议，不能自动标为业务质量已验收。模型自评分必须注明“模型自检”。

## 真人共创

如未来取得内部成员授权与真实作品，先建立作者—作品—编辑—用户反馈的对应表，再追加方法。组织一次匿名同题试写：同一份匿名事实，分别写信、档案、记忆；让不同状态客户盲评“像我吗、愿意留吗、有没有让我不舒服的话”。只将经人评通过的通用方法纳入此 Skill。
